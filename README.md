# Invaders TS

Reimplementation of Taito's _Space Invaders_ using HTML5 canvas and Typescript.
Just for kicks and since I haven't done an HTML5 canvas app in a while.
_Space Invaders_, being quite a simple game, is a good test drive project for different frameworks/stacks.

# Run Debug Server

The following command runs a local debug server with live (not hot) reloading.

```
npm run debug
```
